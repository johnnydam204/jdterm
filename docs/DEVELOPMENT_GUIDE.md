# JDTerm Development Guide

## Principles

1. Single Responsibility Principle.
2. Dependency Injection.
3. No global variables.
4. One package = one responsibility.
5. main.go only starts App.

## Git Commit Style

* feat(...)
* fix(...)
* refactor(...)
* docs(...)
* test(...)

## Workflow

1. Create feature branch.
2. Build.
3. Test.
4. Commit.
5. Merge.

## Testing

Every Sprint must compile and be runnable.
